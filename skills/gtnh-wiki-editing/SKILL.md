# GTNH 中文维基编辑

## 什么时候用

需要新建或修改 GTNH 中文维基上的条目、模板、模块或 Data 页面时使用。

## 基本流程

1. **先读后改**：用 MediaWiki API 取回页面当前源码，在它的基础上修改，不要凭记忆重写整页。
2. **先预览**：保存前用 `action=parse`（传入 `text` 和 `title`）预览，确认没有 Lua 错误，条目的校验提示也已处理。
3. **保存**：写清楚编辑摘要；短时间内批量编辑时使用机器人账号，并在请求中带上 `bot=1`。
4. **核对**：保存后清除页面缓存，再读取渲染结果确认。

## 写法约定

- 物品、维度尽量用 `{{Item|名称}}`，不要只写纯文字。
- 条目页使用 `{{条目/…}}` 系列模板，注释、导航等通用章节会自动生成，不要再手写。
- 链接写到页面的实际标题，不要链到重定向页。
- 内容以游戏数据和源码为准；查不到依据的说法不要写进页面。

## 账号

- 机器人账号读取环境变量 `BOT_USERNAME`、`BOT_PASSWORD`，登录后先确认 API 返回的用户名，再开始写入。
- 不要把账号、密码或令牌写进页面、提交记录或日志。
